# StreamBox free channels

The optional "Free channels" list offered by the StreamBox IPTV Player app.

- Only channels that their own broadcasters stream for free on the web (news, public TV, Quran channels).
- No paid, sports-rights, movie or series channels.
- Every link was checked before it was added. Live links change often: a broken one is fixed here, no app update needed.

Channels and logos belong to their respective broadcasters. To report a broken link, or a channel that should not be here, open an issue.
